# 记忆有效性判别与消融

实现为确定性规则，不是训练出的神经网络或第二个LLM。入口为 `robopilot/memory_validity.py`，数据库接口为 `MissionStore.assess_memory`。

观测新增地点配置摘要context_id；旧数据库无需迁移，缺少摘要的旧记录保留为历史，但不能作为当前证据。摘要覆盖地点坐标配置，不是SLAM地图哈希，也无法识别相同坐标下家具、物体或世界变化。

判定考虑目标、后端、检查点、任务ID、时间、图像证据引用、最新观测与最近肯定。状态包括missing、context_mismatch、needs_refresh、expired、historical_clue、superseded、current_evidence。门状态策略TTL为30秒，其他目标300秒；TTL内也不保证世界不变。跨任务记录始终只能作为线索，本次任务同检查点明确、有证据且未超时的观测才可回答当前条件。后续unknown不恢复旧肯定；后续否定只覆盖同检查点，不推断全局不存在。

原有last_seen仍表示“最后一次发现”，不会被否定观测删除；应结合validity.latest和reasons理解，不能拿last_seen直接回答现在是否存在。

接入位置：静态规划上下文、Agent query_memory工具、inspect_target完成后的发现门控，以及固定计划/Agent观测报告。Agent必须导航和现场检查的原有执行契约保留；模型不能通过历史记忆直接完成任务。固定任务也在观测中记录判别结果。证据路径是来源引用检查，不是图像真实性、磁盘完整性或VLM正确性的证明。

## 已运行的离线配对实验

14个人工构造案例，同一历史、当前真值及时间分别运行三种策略。覆盖近期状态改变/未变、超时、后续否定、后续unknown、配置改变、旧记录缺配置、缺证据、未来时间、空历史、本次正负观测。

|策略|正确任务|错误复用|需要新观测次数|
|---|---:|---:|---:|
|允许最后肯定直接回答的消融基线|6/14|8|2|
|有效性判别器|14/14|0|12|
|原有强制复查策略|14/14|0|14|

复查使用理想真值oracle，非调用VLM：这验证门控是否阻断错误复用，不证明真实视觉100%准确。8→0是此人工压力集相对宽松基线的结果，不能写成真实机器人错误率下降100%。原生产流程已有强制复查，因此相对原流程没有测得准确率提升。两个本次已有观测样本可复用，其他12个都复查；不是证明真实任务节约两次导航。

原始场景、逐项结果及Python策略耗时在 `runs/memory-validity-20261031/results.json`；报告为同目录report.md。微秒计时是离线策略调用时间，包含公共评分准备，不用来比较速度。此次未启动Gazebo或调用API，未测实际任务总耗时。真实耗时需在相同初始世界、相同变化和任务顺序下分别运行策略；记录导航、VLM、复查、总墙上时间及失败，不能套用此前91.56秒的不同实验。

复现（输出目录必须未存在）：

```bash
source /opt/ros/jazzy/setup.bash
PYTHONPATH=src/robopilot:$PYTHONPATH /usr/bin/python3 scripts/measure_memory_validity.py --output runs/memory-validity-new
```

当前限制：规则阈值未做数据驱动标定；同时间观测依输入/数据库次序；记录来源不是安全认证；长期数据库查询尚未优化；未进行真实LLM是否误用线索的随机对照，也未实施跨运行记忆直接跳过巡检。
